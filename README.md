# Ali Rava

**Software Developer · Backend Focus · Iran**

I build web applications, backend services, and developer tools with TypeScript, JavaScript, and Python. My work includes project management, automation, and systems that record and verify important events.

## Selected projects

| Project | What it does |
| --- | --- |
| [Audit Trail API](https://github.com/alirava56/audit-trail-service) | Records and queries append-only audit events with scoped API keys, idempotent writes, and a verifiable SHA-256 hash chain. Includes SQLite backup and recovery tools. |
| [IP Sliding Window Rate Limiter](https://github.com/alirava56/IP-Sliding-Window-Rate-Limiter) | Express middleware that applies a per-IP request quota over a sliding window and tells clients when they can retry. |
| [ProjectOS](https://github.com/alirava56/progect_os) | A Persian, right-to-left workspace for managing projects, tasks, infrastructure, and documents. Built with Next.js, with SQLite and PostgreSQL support. |
| [Django OTP API](https://github.com/alirava56/otp_django) | An account-registration prototype that verifies expiring one-time codes before creating users. |
